# Laboratorio 01: Despliegue de SIEM con Wazuh y Detección de Incidentes

## 📌 Objetivo
Desplegar una arquitectura de monitorización de seguridad basada en el SIEM open-source Wazuh para recopilar, analizar y detectar eventos de seguridad en un endpoint Windows.

## 🧰 Entorno de Laboratorio
* **Hipervisor:** Oracle VirtualBox
* **Servidor SIEM:** Ubuntu Server 24.04 LTS (Wazuh Server + Indexer + Dashboard)
* **Endpoint (Víctima):** Windows 10/11 Evaluation (con Agente Wazuh)
* **Red:** Red Privada (Host-Only Network)
